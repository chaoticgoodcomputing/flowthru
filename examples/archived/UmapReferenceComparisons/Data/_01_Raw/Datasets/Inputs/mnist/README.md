## MNIST Handwritten Digits Dataset

Matches the data sourced from [the UMAP Python example projects](https://github.com/lmcinnes/umap).

Dataset of 8x8 handwritten digit images. Retrieved from [scikit-learn via `sklearn.datasets.fetch_openml("mnist_784", version=1)`

```
LeCun, Y., Cortes, C. and Burges, C.J.C. (1998) The MNIST Database of Handwritten Digits. New York, USA. http://yann.lecun.com/exdb/mnist/
```
