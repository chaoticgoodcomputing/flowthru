## Scikit Digits Dataset

Dataset of 8x8 handwritten digit images. Retrieved from [scikit-learn via `.load_digits`](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_digits.html).

Matches the data sourced from [the UMAP Python example projects](https://github.com/lmcinnes/umap).

```
Alpaydin, E. & Kaynak, C. (1998). Optical Recognition of Handwritten Digits [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C50P49.
```
