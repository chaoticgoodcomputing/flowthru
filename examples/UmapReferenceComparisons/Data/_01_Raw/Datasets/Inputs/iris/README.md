## Iris Dataset

Matches the data sourced from [the UMAP Python example projects](https://github.com/lmcinnes/umap).

Dataset of 8x8 handwritten digit images. Retrieved from [scikit-learn via `.load_iris`](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_iris.html).

```
Fisher, R. (1936). Iris [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C56C76.
```
