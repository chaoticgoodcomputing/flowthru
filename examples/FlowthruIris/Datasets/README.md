## Description

The Iris dataset contains 150 instances across 3 classes of iris plants (50 instances per class):
- Iris-setosa
- Iris-versicolor
- Iris-virginica

### Features
- sepal_length: Sepal length in cm
- sepal_width: Sepal width in cm
- petal_length: Petal length in cm
- petal_width: Petal width in cm
- class: Species name

One class is linearly separable from the other two; the latter are not linearly separable from each other.

This is one of the earliest datasets used in the literature on classification methods and widely used in statistics and machine learning.
