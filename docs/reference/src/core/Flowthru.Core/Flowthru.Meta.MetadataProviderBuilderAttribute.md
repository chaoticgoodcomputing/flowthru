## Remarks

<p>
This attribute enables type-safe provider registration via the generic
FlowthruMetadataBuilder.AddProvider&lt;TProvider&gt;(Action&lt;object&gt;?) method.
</p>
<p>
The builder type must:
</p>
<ul><li>Have a public parameterless constructor</li><li>Expose a public <code>Build()</code> method returning <xref href="Flowthru.Meta.Providers.IMetadataProvider" data-throw-if-not-resolved="false"></xref></li></ul>
<p>
<strong>Example:</strong>
</p>
<pre><code class="lang-csharp">[MetadataProviderBuilder(typeof(JsonMetadataProviderBuilder))]
public class JsonMetadataProvider : IMetadataProvider
{
  // ...
}</code></pre>
